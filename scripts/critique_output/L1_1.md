### 2. Narrative critique
- The sequence is clear: a child hears tapping, guesses what it could be, and discovers a cat. The emotional beat is positive at the end.  
- Some phrasing is unnatural for spoken English: “I sit at a mat” should be “on a mat”; “I pat at it” is odd and doesn’t clearly refer to the door.  
- Text-image match is mostly fine. Page 7 shows tapping on a door but the text doesn’t name it (we can’t use “door” yet), so the referent “it” is vague; still workable with art support.  
- Repetition of “Is it a…?” works for beginners and builds suspense. “Tap, tap!” is effective onomatopoeia.

### 3. Level appropriateness
- Phonics: All but “happy” fit the cumulative graphemes/tricky words.  
- Structure targets: The manuscript currently uses 2–3 sentences per page; programme spec for this book is 1 sentence per page of 3–5 words. “Tap, tap!” is only 2 words.  
- Word count: The draft totals roughly 49 words, which fits the 40–80 target, but this conflicts with the “1 sentence per page” rule for this level.  
- Focus sounds s, a, t, p, i, n are well represented (sit, tap, pat, rat, bat, cat, naps).

### 4. Proposed rewrite
Goal: one sentence per page, 3–5 words, fully decodable, natural English, and aligned with images.

- Page 1: Tap, tap, tap!
- Page 5: Is it a rat?
- Page 6: No rat and no bat.
- Page 7: I tap on it.
- Page 8: It is a cat!
- Page 9: I pat the cat.

### 5. Notes for the human editor
- “Happy” was removed because it’s not decodable at this level (y=/ee/, double pp). If you want an explicit feeling beat, a decodable option is “I am glad,” but that would replace Page 9 or require an extra page.  
- The rewrite adheres to “1 sentence per page,” but with six pages it yields only 24 words, below the 40–80 target. To meet the word-count target without breaking the per‑page rule, consider adding 3–6 more pages (e.g., “I sit on a mat.”; “Tap, tap!”; “Is it a bat?”; “The cat sits.”).  
- Page 1 of the original used “I sit at a mat,” which is unnatural; if we add a page for sitting, please use “I sit on a mat.”  
- We cannot name the door on Page 7 (“door” not yet taught). The line “I tap on it.” keeps the action natural while staying within the code. Please ensure the illustration clearly shows the child tapping the door so the referent is obvious.

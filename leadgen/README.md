# MyPhonicsBooks — Lead Generation Pipeline

Outbound engine for MyPhonicsBooks. Pulls leads from public sources, formats CSVs for GoHighLevel import, and runs email/social sequences.

## Three audiences

| Audience | Source | Why this works |
|---|---|---|
| **International schools** (Africa / SE Asia / Egypt / Middle East) | COBIS, BSME, FOBISIA, country-specific directories + each school's public contact page | They teach British curriculum, "Open Window" cultural angle is differentiated, one school = ~50 parents in value |
| **Phonics YouTubers + frustrated parent commenters** | YouTube Data API v3 | Public data, parent intent signals on phonics-pain videos |
| **Teachers via job boards + YouTube** | TES, Tes International, education-jobs.co.uk, niche teacher YouTube channels | Active teaching practitioners |

UK state schools are **not** in scope — the DfE-validated scheme gate is too high without backing.

## Pipeline

```
scrapers/* → output/*.csv → GoHighLevel import → sequences/* → reply-only notifications
```

Each scraper:
1. Reads a seed list of source URLs.
2. Visits each source politely (2s delay, identifying User-Agent, respects robots.txt).
3. Extracts contact info from public pages only (admin@ / info@ / principal@ / admissions@).
4. Writes a GoHighLevel-compatible CSV to `output/`.

A separate `personalize.py` step adds an `intro_line` column using Claude — call it after you've reviewed the raw CSV.

## Sending stack

Send via **GoHighLevel** on a separate sending domain (e.g. `hello.myphonicsbooks.com` or a brand-new `myphonicsbooks-outreach.com`). Keep daily volume under 40/sender/day. Three sequences:
- `sequences/schools_sequence.md` — B2B, curriculum-led, formal.
- `sequences/teachers_sequence.md` — peer-to-peer, classroom-tool framing.
- `sequences/parents_sequence.md` — existing parent funnel (see `../marketing/marketing/PARENT_OUTREACH.md`).

Notifications: GHL "Workflow trigger on reply" → push to Lynden. Suppress opens/sends/bounces noise.

## CSV columns (GHL-compatible)

`first_name, last_name, email, phone, company_name, country, city, source, curriculum, role, website, intro_line`

`intro_line` is generated by `personalize.py` per row; do not bulk-send without it.

## Legal posture

- Public-source-only. No login-walled scraping, no LinkedIn, no purchased lists.
- Each scraper sets a clear User-Agent identifying the project and respects robots.txt.
- B2B school outreach is GDPR-compatible under "legitimate interest" when (a) message is relevant to the recipient's role, (b) personalised, (c) easy unsubscribe.
- Parent outreach: only via opt-in funnels (Skool, lead magnets) — never cold.

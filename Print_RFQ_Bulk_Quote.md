1. **"C" quantity is still blank.** Your draft says C is "one full run at the quantities listed above", but the quantities listed are unique *design counts* (133, 23, 370, 33, 8), not copies. If C is meant to be a real launch print run, tell me how many copies of each design/title you want and I will drop the number in. Right now C reads the same as A to a printer.
2. **Workbook page counts have been rounded to the nearest multiple of 4** for saddle-stitch (see table below). This changes the actual content extent, so the workbook files themselves still need trimming or padding to match before final artwork goes to print.

I've also fixed one spec that would have got you a wildly wrong quote: your premium cards are not "one design per A4 sheet". The actual card trims to 74 x 105mm; a printer will nest several designs on one press sheet themselves.
